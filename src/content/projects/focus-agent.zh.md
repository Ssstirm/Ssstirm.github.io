## 项目简介

Focus Agent 是一个完全由 LLM 驱动的焦点小组仿真系统。每位虚拟参与者都带有自己的人物设定、推理风格和对话记忆；主持人按访谈目标引导小组讨论——和真实焦点小组的流程一致。

## 为什么做

真实焦点小组慢、贵、迭代难。研究者和产品团队经常需要在能招募真实参与者之前先把方案压力测试一遍。Focus Agent 提供了一个快速循环：起草研究、用合成参与者跑一轮、观察对话偏离的位置、修改方案。
